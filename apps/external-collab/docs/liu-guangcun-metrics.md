# 示例开发10看板取数口径

本看板沿用示例开发01看板的取数规则，只把商务员工替换为示例开发10：员工 ID `472`，开发维度，部门 `dept_id=187`。本月为 2026 年方片月 9 月（`month_id=148`），上月为方片月 8 月（`month_id=147`）。

## 筛选规则

- 总业绩和平台签约业绩：调用 `/api/admin/statOrderRevenue/getEmployeeRevenue`，`performance_type=develop`，分别使用 `revenue_type=publish/order/settlement`，总业绩显式传 `platform_id=0`，小红书/抖音/视频号分别传 `platform_id=1/2/5`；读取 `employee_revenue` 中 `employee_id=472` 的 `revenue`，总业绩不通过平台分项相加。
- 十点半业绩：调用 `/api/admin/statOrderRevenue/getSelfGenerateHalfPastTenRevenue`，按对应 `month_id`、`revenue_type` 和 `employee_id=472` 取员工行的 `revenue`。
- 自孵（不包含十点半）业绩：调用 `/api/admin/statOrderRevenue/getSelfGenerateBusinessEmployeeRevenue`，按对应 `month_id`、`revenue_type`、`performance_type=develop` 和 `employee_id=472` 取员工行的 `revenue`，不取部门聚合值。
- 外采：订单类型 `order_type=3`，结款商务 `payment_business_employee_id=472`，有效状态保留 `100/200/300`，金额加总 `income_money`（公司总收益/公司收益），单数为筛选结果数量。
- 外采时间字段：发布、结款使用 `payment_time`；成单使用 `order_date`。订单接口的时间区间使用字符串形式的半开区间 `[start,end)`，不是数组参数。
